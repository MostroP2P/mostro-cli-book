# mostro-cli JSON Interface Book

Online: **https://mostro.network/mostro-cli-book/**

A guide for people and programs that drive [mostro-cli](https://github.com/MostroP2P/mostro-cli)
through its machine interface (`--output json`): generic wrappers, bots, GUIs, MCP servers
and AI agents.

It works like the [Mostro protocol book](https://mostro.network/protocol/), but one level up:
the protocol book explains the Nostr messages between a client and the Mostro daemon. This
book explains the commands of the CLI and the JSON documents they print.

## What is in it

| Path | Content |
| --- | --- |
| `src/` | The book pages (mdBook). Start at `src/introduction.md`. |
| `examples/` | 154 JSON outcomes, one file per case, listed in `examples/index.json` with the exact command line. |
| `schemas/` | The JSON Schemas (Draft 2020-12) generated by the CLI, one input and one output schema per command, plus a hand-written generic envelope schema. |
| `wrappers/` | Small tested wrappers: Python, TypeScript, Rust, shell. |
| `generated/` | Example sections of the command pages, written by `scripts/gen_examples_page.py`. Do not edit. |
| `scripts/` | Tools to refresh the schemas and the fixture examples and to validate every example. |
| `AGENTS.md` | Rules for an AI (or a human) editing this book. |

## Read it

```sh
cargo install mdbook        # once
mdbook serve                # http://localhost:3000
mdbook build                # static site in ./book
```

The Markdown also reads fine on GitHub, except that the JSON examples are pulled in with
`{{#include}}`; follow the link printed under each example to see the file.

## Keep it true

The book is checked against the binary it documents:

```sh
# 1. regenerate schemas from the binary (needs jq)
MOSTRO_CLI=../mostro-cli/target/debug/mostro-cli scripts/refresh_schemas.sh
# 2. refresh the examples that come from the CLI's test fixtures
python3 scripts/import_fixtures.py --cli-repo ../mostro-cli
# 3. validate every example against the schemas (needs `pip install jsonschema`)
python3 scripts/validate_examples.py
# 4. regenerate the example catalogue page
python3 scripts/gen_examples_page.py
```
